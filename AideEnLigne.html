PassKeep — Aide en ligne

Ce guide explique toutes les fonctions principales de l'application : création de compte, connexion, gestion des mots de passe, paramètres et bonnes pratiques de sécurité.

1) Démarrage rapide

  1. Ouvre l'application et choisis S'inscrire si tu n'as pas encore de compte.
  2. Renseigne ton nom, ton e-mail et un mot de passe pour créer ton coffre-fort.
  3. Connecte-toi depuis l'écran Connexion.
  4. Dans l'écran principal, clique sur + Ajouter un mot de passe.
  5. Affiche/masque un mot de passe avec l'icône œil, ou supprime une entrée avec l'icône corbeille.
Compte utilisateur

2) Inscription

Le formulaire d'inscription demande :

  • Nom complet
  • Adresse e-mail
  • Mot de passe

Validation : tous les champs sont obligatoires.

Attention : l'e-mail doit être unique (impossible de créer deux comptes avec la même adresse).

Accès

3) Connexion

Sur l'écran de connexion, saisis ton e-mail et ton mot de passe puis clique sur Se connecter.

En cas d'erreur, le message "Email ou mot de passe incorrect." s'affiche.

La case Rester connecté est visible mais peut dépendre d'une évolution future selon ton environnement.

Cœur de l'application

4) Gestion des profils de connexion

Chaque profil représente un compte externe (Google, GitHub, banque, etc.).

Fonction Description
Ajouter un profil Ajoute un service avec son URL, login et mot de passe depuis le bouton + Ajouter un mot de passe.
Générer un mot de passe Le bouton Générer propose automatiquement un mot de passe.
Afficher / masquer L'icône œil permet de voir le mot de passe en clair puis de le masquer.
Supprimer une entrée L'icône corbeille supprime immédiatement le profil sélectionné.
Modifier une entrée Le bouton modifier est présent visuellement et peut être complété dans une version future.

Important : la suppression est définitive après validation interne.

Paramètres

5) Dictionnaire (génération de mots de passe)

Depuis l'icône engrenage, ouvre les paramètres puis la section dictionnaire.

Importer un dictionnaire

  • Clique sur Importer.
  • Sélectionne un fichier texte .txt contenant une liste de mots.
  • Un message confirme la réussite ou l'échec de l'import.

Supprimer les mots

  • Clique sur Supprimer pour vider totalement le dictionnaire.
  • Un message de retour indique le résultat de l'opération.
Sécurité

6) Recommandations importantes

  • Choisis un mot de passe principal long et unique.
  • Évite de réutiliser le même mot de passe entre plusieurs services.
  • Préserve l'accès à ta machine : si la session est ouverte, tes informations peuvent être visibles.
  • Fais des sauvegardes régulières de ton environnement si nécessaire.
FAQ

7) Questions fréquentes

  • Je ne peux pas créer mon compte : vérifie que tous les champs sont remplis et que l'e-mail n'existe pas déjà.
  • Je n'arrive pas à me connecter : vérifie ton e-mail, ton mot de passe, et la casse (majuscules/minuscules).
  • Le mot de passe ne s'affiche pas : clique sur l'icône œil dans la ligne du profil concerné.
  • Que faire après suppression d'un profil ? La suppression est permanente, il faut recréer l'entrée manuellement.
